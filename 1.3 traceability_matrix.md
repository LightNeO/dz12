# Traceability Matrix — AirGuard

**Схема:** Вимога з PRD → Тестовий файл → Тест-функція.

Кожна вимога з `PRD.md` покрита хоча б одним тестом; навпаки — кожен тест посилається
на ID вимоги (у docstring тесту). Пріоритет вимоги відображено в порядку запуску профілів:
`smoke` → `functional` → `e2e` → `stability`.
