# DZ-12 — AirGuard C1: HIL-стенд та E2E-автоматизація

## Обраний IoT-продукт

**AirGuard C1** — розумний настільний монітор якості повітря для дому/офісу.

Пристрій вимірює концентрацію CO2 (еквівалент), температуру та відносну вологість, показує
стан повітря світлодіодом і звуковим сигналом, а також публікує показники у JSON по MQTT —
щоб значення бачив мобільний застосунок / дашборд користувача.

| Параметр | Значення |
|---|---|
| DUT | ESP32-S3 DevKitC-1 (N16R8) |
| Сенсор CO2 | MQ-135 (аналоговий, 0–3.3 В, 400–5000 ppm) |
| Сенсор температури/вологості | SHT31 (I2C) |
| Індикація | RGB LED (стан повітря), buzzer (тривога) |
| Мережа | WiFi 2.4 ГГц → MQTT-брокер |
| Інтерфейс QA | CLI через UART (USB) 115200 8N1 |
| Живлення | 5 В USB (керується реле HIL-стенда) |
